# 边境协议 v0.6.0 — 五名干员

角色名册现为凛御银灰、重岳、黍、祀、明河；最多四人出战。五人的职业、被动、培养数值与招募价格维护在 `js/game.js` 的 `opDefs`。数值为本作自定义设计，不是官方技能数值。

角色档案与战斗舞台共用 `assets/five-operators.webp` 五等宽图集，顺序依次为上述五人。图片失效会回退原 SVG。存档键不变，兼容 v1–v4 到 v5 的数据迁移，前五名角色原有等级、装备沿用，其余七名旧角色的信息归档在 `legacyRoster`。未入队旧角色的装备依旧存于库存。

这是非官方同人美术与独立游戏，不代表原游戏版权方。
