# 边境协议 / FRONTIER PROTOCOL

**v0.4.0 · 深层远征与干员编队。** 本作是原创工业科幻放置养成游戏，借鉴开源作品 Progress Knight / Trimps 的数值循环，但没有移植其代码或商业素材。

## 游玩

使用 GitHub Pages 发布仓库根目录的 `index.html`。游戏存档保存在当前浏览器 `localStorage`；首次打开新域名时请导入旧存档。电脑、手机浏览器均可运行。

## v0.4 内容

- 12 名可招募干员，四人主动出战，小队之外的干员留在后备席并可继续配装、集中训练。
- 干员专精包括首领伤害、医疗恢复、战术防护、物资掉落、全队增伤等；仅在出战时生效。
- 30 个独立命名、分成 6 章的主线区域。每章有压轴首领；完成 30 区后可继续通过程序生成深层区域，最多至第 999 区。
- 关卡强度、每区击杀目标数、首领耐久按章节增长；前几区为入门，后续长期成长需要装备与转生。
- 战利品仓库电脑每排五件、中屏四件、平板三件、手机两件。查看装备详情仍可进行锁定、拆解、独立配装。
- 沿用此前的升级仓库、自动配装、自动分解与词条系统。
- 兼容 v1 / v2 / v3 存档（自动迁移至 v4），保留旧装备、旧角色、旧材料。

## 代码维护

- `index.html`：DOM 页面结构、八个功能页。
- `css/styles.css`：主题配色、装备网格、章节导航、响应式页面。
- `js/game.js`：经济、30 区地图、编队、干员专精、存档迁移、战斗、装备。
- `js/art.js`：原创工科风 SVG 设施和 12 名干员剪影生成器（无外部图片依赖）。
- `tests/smoke.cjs`、`tests/inventory_extended.cjs`、`tests/zone_roster.cjs`、`tests/browser_test.py`：逻辑及浏览器回归测试。

**开发约定：**关键逻辑用中文注释，新字段必须在 `fresh()` 和 `hydrate()` 同步，增加功能应补测试并更新 `CHANGELOG.md`。谨慎调整 `SAVEKEY`，它与旧存档兼容直接相关。

## 美术参考

整体界面氛围参考工业科幻和战术档案展示；12 名干员均保留原创名字与形象，使用统一的 SVG 角色形象生成器。当前是简化档案立绘，并非《明日方舟》《明日方舟：终末地》官方角色或官方美术复刻。若后续要为特定官方干员制作同人形象，请先指定角色，并将二次创作与项目原创角色分开管理。
